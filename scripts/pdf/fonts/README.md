# Embedded fonts

These unmodified font files are redistributed under the SIL Open Font License
1.1. Each family's license and copyright statement are preserved alongside the
fonts. The generated PDF is not subject to the font license.

| Family | Use |
|---|---|
| Carlito | Body, headings, tables and running text. |
| IBM Plex Serif | Cover title and subtitle. |
| IBM Plex Mono | Literal code. |
| Noto Sans Math | Mathematical glyphs unavailable in the selected text font. |

`manifest.json` records the exact upstream URLs and SHA-256 digests. The fonts
are not renamed internally, modified, downloaded at rendering time or loaded
from the operating system. Family names are used only to identify the original
font software, not to suggest endorsement of Document Swarm.
